## Metadata

| Table name                | D3_ELIGIBILITY                                                                                                                                                                                                                                             |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Description               | Time-varying status data set for the eligible population. A status is a period of time within an individual, defined by a start and end date where a person has a specific combination of different variables.                                             |
| Source                    | D3_MULTIVARIATE_EPISODES; D3_CONCEPTS                                                                                                                                                                                                                      |
| Step                      | transformations/T3_study_design/source_code/calculate_eligibility.R                                                                                                                                                                                        |
| Content                   |                                                                                                                                                                                                                                                            |
| Population                | All individuals who are in the data instance who have observations that fall within the study period<br /> (i.e. are registered in the data source between start study date (01-01-2022) and end study date (31-12-2024))), and are potentially eligible. |
| Unit of Observation (UoO) | Spell/Status; One or more rows per person (key: person_id, start_episode)                                                                                                                                                                                          |
