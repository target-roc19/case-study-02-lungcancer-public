## Metadata

| Table name                | D4_StudyCohort_Covariates                                                                                                                                 |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Description               | Table of covariate values evaluated at baseline (T0) for the study cohort. Used to create baseline descriptives tables; fit baseline weights models, etc. |
| Source                    | D4_StudyCohort; D4_STUDYVARIABLES_ANCHORED; D3_PERSONS; combined_anchor_metadata.csv                                          |
| Step                      | transformations/T3_study_design/source_code/get_wide_anchored_covariates.R                                      |
| Content                   | Covariate values anchored at T0 for baseline characteristics and propensity score weighting                                                               |
| Population                | Selected study cohort                                                                                                                                     |
| Unit of Observation (UoO) | One row per person in the study cohort                                                                                                                    |
