## Metadata

| Table name                | D4_StudyCohort_FUP                                                                                                                                                                                                                                                        |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Description               | Data containing information on follow ups in the selected study cohort.<br />Two parts: first, dates of censoring events and any additional post-selection inclusion/exclusions. <br />Second: from this information, computed censoring date and reason; follow-up time. |
| Source                    | D4_StudyCohort; D3_PERSONS; configuration/config_values.yaml                                                                                                                                                                                                              |
| Step                      | transformations/T3_study_design/source_code/calculate_fup.R                                                                                                                                                                                                               |
| Content                   | Computing censoring dates, follow-up time, and an indication for outcome event                                                                                                                                                                                            |
| Population                | Selected study cohort                                                                                                                                                                                                                                                     |
| Unit of Observation (UoO) | One row per person in the study cohort                                                                                                                                                                                                                                    |

| general_end_fup        |                    |           | x        | Date      | min(date_death, end_study_period, end_of_data_collection, max_fup_date)                          | earliest date follow-up end for this patient                                                  |            |
| reason_censoring       |                    |           | x        | Character | First matching rule, in order:<br />1. Death (general_end_fup == date_death)<br />2. End of max follow-up<br />3. End of data collection<br />4. End of study period | reason for follow-up end. Because end_of_data_collection and end_study_period are currently the same date, "End of study period" is never reached | Death, End of max follow-up, End of data collection, End of study period |
| fup_length_days        |                    |           | x        | Numeric   | general_end_fup - T0 + 1                                                                         | length of follow-up in days                                                                    |            |

| event_death            |                    |           | x        | Integer   | IF reason_censoring == "Death" then 1 ELSE 0                                                     | event indicator. 1 = death observed during follow-up, 0 = censored (alive at end of follow-up) |            |
