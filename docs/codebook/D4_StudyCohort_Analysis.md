## Metadata

| Table name                | D4_StudyCohort_Analysis                                                                                                                                                           |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Description               | Person-level analysis data set for the outcome analyses. Joins follow-up time, propensity score and IP weight, and the forest-plot subgroup labels onto one row per person.       |
| Source                    | D4_StudyCohort_FUP; D4_StudyCohort_IPTW; D4_StudyCohort_Covariates                                                                                                                |
| Step                      | transformations/T4_statistical_analysis/source_code/create_d4_StudyCohort_Analysis.R                                                                                              |
| Content                   | Follow-up time and event indicator, propensity score and IP weight, and the two subgroup labels used by the forest plot. |
| Population                | Every person in D4_StudyCohort_FUP.   |
| Unit of Observation (UoO) | One row per person in the study cohort                                                      |
